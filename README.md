## What is computed vs. cited

* **Computed and proven optimal here:** f(n,3) for n = 1–5 (2, 3, 5, 8, 12).
* **Not proven here:** for n = 6 the solver stops at its time limit with a gap (status recorded in `data/covering.json`). f(6,3)=18 and the bounds for n = 7, 8 are taken from Adriaensen et al. (arXiv:2602.01080) and Kuang & Wang (arXiv:2608.13252).
* **Two-copy bounds:** the completed SciPy 1.18.0 rerun recovers
  227/256 <= S2(0) <= 238/256, with a 1200-second time limit and no optimal
  status. Both the heuristic and the returned MILP incumbent are re-scored.
  The raw bound and gap are in `data/no_comm_n2_exact.json`; numerical manuscript
  macros are generated from these current data, not copied from a prior run.
* Time-limited runs (n = 6 covering, exact n = 2 MILP) can give slightly different incumbents and bounds on other hardware.

## Discover Quantum Science submission

Prepared as a **Research** submission, not a claim of journal acceptance.
Repository: https://github.com/VesterlundCoder/cqa07-paper-v1.0
Version archive: https://doi.org/10.5281/zenodo.24459185

The numerical pipeline needs approximately 22 minutes because it includes
120-second covering limits and a 1200-second two-copy limit. Use a separate
Python 3.12+ environment. `requirements-lock.txt` records the complete executed
environment; `data/runtime.json` records interpreter and source hashes.
HiGHS-specific thread/seed options are passed through SciPy; its warning about
forwarding these options is expected and retained.

`logs/` contains per-script output and the pipeline exit status. Solver
optimality is understood at floating-point tolerances; no exact-arithmetic
certificate is claimed. The analytic main theorem is independent of the
time-limited optimization. The exhaustive protocol check covers 1,118,480
input pairs across n=1,...,5.

`REFERENCE_NOTES.md` records the primary-source/task alignment checks.
`code/build_word.py` produces the optional Word copy with resolved numeric
citations and cross-references after TeX compilation; it requires Pandoc.
The TeX/PDF is canonical. The journal-source ZIP contains only compilation
inputs. Cover letter/checklist are separate submission documents.
